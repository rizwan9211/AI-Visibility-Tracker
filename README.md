# AI-Visibility-Tracker

AI Search Visibility Tracker built with Appwrite TablesDB & VectorsDB for Appwrite Hackathon.

## What is this?
Ask an AI for "best financial service in Noida" - Is your brand in the answer? This tool checks how visible your brand is in AI answers like Gemini, ChatGPT, Perplexity.

## Live Demo
https://rizwan9211.github.io/AI-Visibility-Tracker/

## Tech Stack
- Appwrite TablesDB
- Appwrite VectorsDB
- Gemini API
- HTML / CSS / JS
